# Asset placement

Place the images you provided using these exact filenames:

## Ships
- `assets/ships/player_f22_a.png`
- `assets/ships/player_f22_b.png`
- `assets/ships/player_f22_c.png`
- `assets/ships/player_f22_d.png`
- `assets/ships/enemy_f15_a.png`
- `assets/ships/enemy_f15_b.png`

## Maps
- `assets/maps/desert.png`
- `assets/maps/highway.png`
- `assets/maps/city.png`
- `assets/maps/stadium.png`

The game automatically loads these images and falls back to procedural graphics when files are missing.
